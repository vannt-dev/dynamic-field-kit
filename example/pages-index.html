Dynamic Field Kit

One schema-driven form engine, three frameworks. Describe the fields once as a FieldDescription[] and render them in React, Vue or Angular with your own components.

Read the handbook GitHub npm 
npm install @dynamic-field-kit/core @dynamic-field-kit/react   # or /vue, /angular
